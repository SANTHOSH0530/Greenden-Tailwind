# 🌿 Greenden – Plant Store Website

A responsive plant store website built using **HTML, Tailwind CSS, and JavaScript**. Greenden provides a clean and user-friendly interface for exploring plants and learning about the store.

## ✨ Features

- Responsive website design
- Navigation bar
- Home page with hero section
- Plant product listings
- Best-selling products section
- About Us section
- Contact Us page
- Newsletter subscription section
- Tailwind CSS utility classes
- Custom fonts using Google Fonts

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- Node.js and npm
- Google Fonts

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the Project Folder

```bash
cd GREENDEN
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Build Tailwind CSS

```bash
npx tailwindcss -i ./src/input.css -o ./src/output.css --watch
```

Keep this command running while developing so Tailwind CSS can rebuild when your files change.

### 5. Run the Website

Open `index.html` in your browser or use the Live Server extension in VS Code.
