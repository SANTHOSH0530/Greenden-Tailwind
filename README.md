# 🌿 Greenden – Responsive Plant Store Website

A responsive plant store website built using **HTML5, Tailwind CSS, and JavaScript**. Greenden provides a clean and user-friendly interface to explore plant products, search for products, and contact the store.

## ✨ Features

- 📱 Responsive website design
- 🏠 Home page with hero section
- 🛍️ Products page with plant listings
- 🔍 **Real-time product search functionality**
- 🌱 Best-selling plants section
- 📩 Contact page
- 📱 Responsive navigation bar with a side navbar
- 🎨 Modern UI using Tailwind CSS
- 🔤 Custom typography using Google Fonts (Poppins)
- 🖼️ Plant images and visual elements

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **Tailwind CSS** – Styling and responsive layouts
- **JavaScript** – Product search and navigation interactions
- **Google Fonts** – Poppins typography
- **Git & GitHub** – Version control and project hosting

## 🔍 Product Search Functionality

The Products page includes a JavaScript-powered search feature that filters plant products based on the text entered by the user.

**How it works:**

1. The user enters a product name in the search box.
2. JavaScript reads the search input.
3. Product names are compared without case sensitivity.
4. Matching products remain visible, while non-matching products are hidden.

Example searches:
- `Rose`
- `Snake`
- `Lily`
- `White Rose`
